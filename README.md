# Greatest of All Time

An interactive dashboard on football's greatest player: 21 legends, from Pelé, Puskás and Di Stéfano to Mbappé and Haaland, measured on the same 16 criteria. Visitors choose the comparison group, normalisation method and weights; a Monte Carlo panel tests how stable the ranking is. Methods follow the OECD/JRC composite-indicator handbook and Saisana, Saltelli & Tarantola (2005); see `research/METHODOLOGY.md`.

The whole site is one file, `index.html`, at the root of this repository. It loads D3 from cdnjs and fonts from Google Fonts, and needs no server code.

## Hosting

- **GitHub Pages**: Settings → Pages → Build and deployment → Deploy from a branch → `main`, `/ (root)`.
- **Vercel**: Add New → Project → import this repository → Framework preset "Other" → Deploy. Every push redeploys.
- **Netlify or Cloudflare Pages**: point them at this repository with no build command and `/` as the publish directory.

## What is here

| Path | What it is |
|---|---|
| `index.html` | The site. Generated by `site/build.py`; do not edit by hand. |
| `site/src/page.html`, `site/src/app.js` | Page markup and styles; chart and interaction code (D3 7.8.5). |
| `site/data/data.js` | The generated dataset (`window.FG`). |
| `site/build.py` | Assembles `index.html` (and `site/dist/` for the claude.ai artifact). |
| `research/METHODOLOGY.md` | Definitions, scoring, uncertainty analysis, references. |
| `research/recent_and_leaderboards.md`, `research/leaderboards.json` | Sourced 2025–26 facts and all-time leaderboards, with a URL for every claim. |
| `research/career_seasons.json`, `research/honours.json` | Season-by-season career tables and honours for all 21 players, from English Wikipedia. |
| `research/h2h_metrics.json` | Match-level metrics for Ronaldo and Messi (exact ages, rounds, goal types). |
| `research/scripts/` | The data pipeline. |

## Rebuilding the data

The raw third-party inputs are not stored here; the first two commands download them again.

```bash
bash research/scripts/fetch_mvr.sh
```

```bash
cd research && python3 scripts/extract_career_stats.py && python3 scripts/extract_honours.py
```

```bash
python3 scripts/mvr_to_csv.py mvr && python3 scripts/compute_h2h.py mvr h2h_metrics.json
```

```bash
python3 scripts/build_data.py . ../site/data/data.js && cd ../site && python3 build.py
```

`build_data.py` stops with an error if Ronaldo's or Messi's totals differ between Wikipedia and the match records, if the opponent-ranking splits do not add up, or if a league in the career tables is unclassified. It prints the leader of every criterion. The extraction scripts need `pip install wikitextparser requests`.
